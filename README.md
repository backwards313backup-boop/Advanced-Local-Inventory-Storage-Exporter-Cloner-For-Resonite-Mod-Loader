Extract your whole Resonite inventory to a local drive easily with this plugin. Also you can spawn these items from the local storage inventory without waiting for Resonites remote servers and without using up Resonite cloud storage space.
You can sort by true file size and also save items as either .resonitepackages that are fully self contained or a de-duplication for multiple assets using shared assets locally, which saves a lot of storage on your drive you are cloning to. You can also just save single items to the inventory at a time.
Exports files to the same folder hierarchy as they are in your inventory. You can also search your local inventory with partial text and it's extremely fast compared to the default inventory as it includes performance enhancements for responsiveness.

This plugin requires Resonite Mod Loader.
